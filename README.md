# Employee Management System

Employee Management System is a web application developed using **ASP.NET Core MVC, C#, Entity Framework Core, and SQL Server**.

## Features
- Add Employee
- View Employee
- Edit Employee
- Delete Employee
- Employee data management using SQL Server

## Technologies
- ASP.NET Core MVC
- C#
- Entity Framework Core
- SQL Server
- HTML, CSS, Bootstrap

## Purpose
This project helps to manage employee records and demonstrates **CRUD operations using Entity Framework Core**.
